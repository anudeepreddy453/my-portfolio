How visitor information is handled

This portfolio stays closed until the browser shares a one-time location reading and the server accepts it. That request is a location permission, not a security check and not proof of identity.

Precise location

If you choose Enable location & continue, the browser asks for permission with its own prompt. After you allow it, the site reads latitude, longitude, accuracy in meters, and the reading’s timestamp once. It does not keep watching your location.

If you deny permission, dismiss the prompt, or the browser cannot provide a location, the portfolio stays closed.

Approximate network location

The server also sees the IP address that connected to this site. From that address it may look up an approximate country, region, city, and network provider. That result is an IP estimate. It is not GPS, and it is not a street address.

Device and pages

The site records ordinary request details: browser and operating system from the user agent, language, time zone, screen size if you continue, the page you opened, and the referring site. It does not build a hidden browser fingerprint.

How this is used

{{ profile.short_name }} uses these records to see where visits come from and how the site is used. They are not sold or shared with unrelated third parties. IP geolocation uses the configured lookup provider only to estimate the network location.

How long it is kept

GPS coordinates and IP coordinates are removed after {{ gps_days }} days. Session and page history are removed after {{ activity_days }} days. A granted visit stays open for {{ session_hours }} hours, then the location step is required again.

Your request

To ask about a visit record, or to ask for deletion, email {{ profile.email }}. Include the approximate time of the visit. The site owner can delete a visitor record, delete stored GPS coordinates, or revoke a session from the private admin dashboard.
